# KORE.

**Elegance in code & architecture.**

KORE is a concept website for a fictional next-generation computing platform, a deterministic runtime that bridges human thought and machine execution. The site presents the brand through four chapters (Philosophy, Architecture, Ecosystem, Vision) with a minimal, editorial look, live code snippets and interactive 3D.

🔗 **Live site:** https://0ph3li.github.io/KORE./

> *"The power to change the world is hidden in the code."*

---

## ✦ Pages

| Page | Description |
|------|-------------|
| `index.html` | Home: manifesto, code snippets, multi-paradigm engine (Rust, TypeScript, WGSL) |
| `philosophy.html` | The four axioms behind KORE: purity, anti-entropy, distribution |
| `architecture.html` | The four-tier stack, with interactive layer inspection and live telemetry |
| `ecosystem.html` | Package directory and an interactive stack builder that generates a `kore.config.json` |
| `vision.html` | The 2030 horizon, with a real-time 3D object you can morph and customize |

## ✦ Features

- **Interactive 3D scene** built with Three.js: switch shapes (Torus Knot, Cyber Sphere, Crystal Matrix), change rotation speed and wireframe color
- **Layer inspector:** click through each tier of the architecture stack
- **Stack builder:** toggle modules and watch the config file update in real time, then copy it
- **Animated telemetry** and code blocks in a terminal-inspired style
- Editorial typography mixing serif, sans and monospace

## ✦ Built with

- HTML, CSS and vanilla JavaScript
- [Three.js](https://threejs.org/) for the 3D scenes
- Google Fonts: Instrument Serif, Inter, JetBrains Mono
- Hosted on GitHub Pages
